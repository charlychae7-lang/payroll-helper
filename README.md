# 급여 업무 도우미

![급여 업무 도우미](share-card.png)

**바로 사용하기: https://charlychae7-lang.github.io/payroll-helper/**

소규모 사업장의 월 급여를 계산하고 급여대장과 급여명세서를 만드는 웹 앱입니다. 설치, 가입, AI 서비스 연결 없이 브라우저에서 동작합니다.

## 할 수 있는 일

- 상용직 급여: 일할계산, 상여, 휴가비, 4대보험, 근로소득 간이세액표, 연말정산 정산액
- 일용직 급여: 출역(공수) 입력, 일용 소득세, 고용보험, 국민연금·건강보험 간이 판정
- 급여대장, 일용노무비 명세, 급여명세서 인쇄와 PDF, 엑셀 내보내기
- 직원별 PDF 일괄 저장, 카카오톡 안내 문구 복사, 이메일 일괄 발송 도구
- 월 마감, 백업과 복원, 앱 안의 사용설명서

## 사용 방법

| 방법 | 순서 |
|---|---|
| 웹에서 사용 | 위 주소를 PC의 Edge나 Chrome으로 엽니다. 주소창의 설치 아이콘으로 앱처럼 추가할 수 있습니다. |
| 내려받아 사용 (실제 급여에 권장) | [ZIP 내려받기](https://github.com/charlychae7-lang/payroll-helper/archive/refs/heads/main.zip) → 압축 풀기 → `index.html` 두 번 누르기 |

처음에는 **설정·백업**에서 회사명을 정하고 **직원 관리**에서 직원을 추가합니다. **예시 자료로 둘러보기**로 먼저 살펴볼 수 있습니다.

## 이메일 발송 도구

`급여명세서_메일발송.pyw`는 Python 3이 설치된 Windows PC에서 두 번 눌러 실행합니다. 추가 패키지는 필요 없습니다.

1. 직원의 이메일을 입력하고, 급여명세서 화면에서 **메일 발송용 파일 저장**을 누릅니다.
2. 도구에서 메일 서비스, 보내는 주소, 앱 비밀번호를 입력합니다. 앱 비밀번호는 저장하지 않습니다.
3. **나에게 시험 발송**으로 확인한 뒤 발송합니다.

## 개인정보와 보안

- 입력한 자료는 사용하는 기기의 브라우저에만 저장됩니다. 이 앱은 자료를 서버로 보내지 않도록 연결을 차단(CSP)했습니다.
- 브라우저의 사이트 데이터를 지우면 자료가 사라집니다. 마감할 때마다 백업하세요.
- 웹 주소(`charlychae7-lang.github.io`)로 쓰면 같은 주소의 다른 페이지와 브라우저 저장 공간을 함께 씁니다. 실제 급여 자료는 내려받은 파일로 사용하는 것을 권합니다.
- 백업, 엑셀, PDF 파일에는 암호가 없습니다. 이 저장소에는 올리지 마세요.

## 꼭 확인하세요

- 요율은 2026년과 2027년 1월분이 들어 있습니다. 2027년 고용보험 요율은 확인 전 값(0.9%)입니다.
- 간이세액표는 2026.2.27 개정판입니다. 2026년 3월 이후 지급분에 맞습니다.
- 건강보험료 상·하한, 연장·주휴수당, 연말정산, 퇴직금은 자동 계산하지 않습니다.
- 계산 결과는 참고용입니다. 지급과 신고 전에 담당자, 세무·노무 전문가 또는 해당 기관에 확인하세요. 사용에 따른 책임은 사용자에게 있습니다.
